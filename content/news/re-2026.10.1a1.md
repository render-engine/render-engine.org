Render Engine 2026.10.1a1 has been released as an alpha release for testing. This versions includes:

- Removing of support for Python 3.10 and adding Python 3.15
- Improved error handling when rendering a `Site`:
  - `Collection.render` will aggregate exceptions from all entries it renders and, if there were exceptions, raise an
  `ExceptionGroup`.
  - All `Exception`s encountered during rendering will be annotated with relevant data to help you understand which
  entry caused the `Exception` to be raised.
  - On completion of rendering all entries the `Site` will, if any `Exception`s occurred, output to `STDERR` the
  annotations from the accumulated `Exception`s and store the complete back traces (including the annotations) to
  a log file in the `Site`'s output directory.

For the full changelog please see <https://github.com/render-engine/render-engine/releases/tag/2026.10.1a1>
